# Video script: Hallucinations

## Scene 1: What is Hallucination?

On-screen:
- Definition
- Why models hallucinate

Narration:

In this scene we define hallucination as false output from an LLM and explain that the model predicts tokens, not truth.

## Scene 2: Types of Hallucinations

On-screen:
- Factual
- Logical
- Contextual

Narration:

We break down the three common categories of hallucinations and give quick examples of each.

## Scene 3: Prompt Engineering Tricks

On-screen:
- Ask for sources
- Use "I don't know" clause

Narration:

Learn how to shape prompts so the model is less likely to fabricate information.

## Scene 4: Retrieval‑Augmented Generation

On-screen:
- Fetch relevant docs
- Combine with model output

Narration:

See how pulling external knowledge before generation dramatically cuts hallucinations.

## Scene 5: Post‑Processing Validation

On-screen:
- Regex checks
- Fact‑check APIs

Narration:

Discover practical validation steps you can run after generation to catch errors before they reach users.

## Scene 6: Real Product Example

On-screen:
- Customer support bot
- Regeneration loop

Narration:

We walk through a concrete chatbot scenario, showing how a verification loop prevents a wrong warranty claim.
