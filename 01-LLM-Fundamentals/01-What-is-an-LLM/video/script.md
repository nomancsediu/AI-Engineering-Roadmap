# Video script: What is an LLM

## Scene 1: What is an LLM?

On-screen:
- Definition
- Why "large" matters

Narration:

An LLM is a massive neural network that predicts text. Its size—both parameters and data—gives it broad language abilities.

## Scene 2: Training Basics

On-screen:
- Next‑token prediction
- Transformer architecture

Narration:

During training the model sees a sequence of words and learns to guess the next one, using attention mechanisms to capture context.

## Scene 3: From Training to Inference

On-screen:
- Prompt input
- Token generation loop

Narration:

After training, you feed a prompt, and the model generates tokens one by one until it finishes the response.

## Scene 4: Prompt Engineering

On-screen:
- Instructions
- Few‑shot examples

Narration:

You can steer the model by crafting prompts that include clear instructions or example interactions.

## Scene 5: LLMs in Products

On-screen:
- Chatbots
- Code assistants

Narration:

Today LLMs power chat assistants, code generators, summarizers, and many other AI features you see in apps.
